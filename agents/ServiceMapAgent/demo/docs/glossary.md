# Glossary

| Word | Meaning |
|------|---------|
| Reservation | Stock held for an order being placed; expires after 15 minutes unless the order confirms it. |
| `CANCEL_PENDING` | Order status while a refund is being retried after billing-service failed. |
| SKU | Stock keeping unit: the product id used by inventory-service. |
| Service token | Client-credentials JWT that services use to call each other; customers can't use these endpoints. |
