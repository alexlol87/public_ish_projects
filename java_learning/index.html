How to use this site If Spring Boot itself still feels shaky, read Spring Boot basics first: every other page assumes you know what a bean, a proxy and a request thread are. Then go through the concurrency pages in order (1 → 4). The interview pages can be read in any order; each answer is collapsible so you can quiz yourself first.

Glossary of abbreviations and terms

Every abbreviation used anywhere on the site, in plain words.

Java & the JVM

JDK
Java Development Kit: compiler (javac), tools and the runtime. What you install to build Java code.
JRE
Java Runtime Environment: just what is needed to run Java. Since Java 11 it is not shipped separately; you use a JDK or a trimmed runtime made with jlink.
JVM
Java Virtual Machine: the program that loads .class files (bytecode) and executes them, manages memory and threads.
JIT
Just-In-Time compiler: turns hot bytecode into native machine code while the program runs.
GC
Garbage Collector: frees memory of objects nobody references any more (G1 is the default; ZGC and Shenandoah are low-pause collectors).
JEP
JDK Enhancement Proposal: the numbered document describing a new Java feature, e.g. JEP 444 = virtual threads.
LTS
Long-Term Support release. Java 17, 21 and 25 are LTS; companies standardize on them.
Preview feature
A finished-but-not-final language/API feature; needs --enable-preview to compile and run.
JMM
Java Memory Model: the rules for when a write made by one thread becomes visible to another (see page 1).
CAS
Compare-And-Swap: a single CPU instruction "set X to new value only if it still equals expected value". The basis of Atomic classes and lock-free code.
OS
Operating System (Linux, macOS, Windows). Platform threads are OS threads.
CPU core
One hardware execution unit. N cores = at most N threads truly running at the same instant.
I/O
Input/Output: network calls, disk reads, database queries. Waiting for I/O is where most server time goes.
NIO
"New I/O" (java.nio): non-blocking sockets, selectors and buffers. Netty is built on it (or on Linux epoll directly).
FIFO / LIFO
First-In-First-Out (a queue) / Last-In-First-Out (a stack).
POJO
Plain Old Java Object: a normal class that does not extend any framework class.
DTO
Data Transfer Object: an object used only to carry data (often a Java record), e.g. the JSON body of a REST call.

Spring & web

Spring Framework
The core library: dependency injection container, web (MVC, WebFlux), transactions, data access helpers.
Spring Boot
An opinionated layer on top of Spring: starters, auto-configuration, embedded server, application.yml, Actuator. Spring Boot 4 (Nov 2025) is built on Spring Framework 7; Boot 3.x on Framework 6.
IoC
Inversion of Control: the framework creates and wires your objects instead of you calling new.
DI
Dependency Injection: the way IoC is done: dependencies are handed to an object (usually through its constructor).
Bean
Any object created and managed by the Spring container.
ApplicationContext
The Spring container: holds all beans and wires them together.
AOP
Aspect-Oriented Programming: adding behaviour (transactions, security, caching, logging) around method calls without touching the method, implemented in Spring with proxies.
Proxy
A generated wrapper object that sits in front of your bean and runs extra logic before/after delegating to it. @Transactional, @Async, @Cacheable all work through proxies.
MVC
Model-View-Controller. "Spring MVC" is the classic servlet-based, blocking web stack.
Servlet
The Java standard API for handling HTTP in a server like Tomcat (Jakarta Servlet). One request = one thread in the classic model.
WebFlux
Spring's reactive, non-blocking web stack, by default running on Netty.
Netty
A Java network library with an event-loop, non-blocking I/O model. WebFlux's default server.
Reactor
Project Reactor: the reactive library behind WebFlux. Types Mono (0..1 value) and Flux (0..N values).
HTTP / HTTPS
HyperText Transfer Protocol (S = over TLS encryption).
REST
REpresentational State Transfer: an API style using HTTP verbs (GET, POST, PUT, PATCH, DELETE) on resources (/orders/42).
JSON / YAML
JavaScript Object Notation (data format for APIs) / "YAML Ain't Markup Language" (indentation-based format used for application.yml).
JPA
Jakarta Persistence API: the standard for mapping Java objects to database tables. Hibernate is the implementation Spring Boot uses.
ORM
Object-Relational Mapping: the general idea behind JPA/Hibernate.
JDBC
Java Database Connectivity: the low-level, blocking API to talk SQL to a database.
R2DBC
Reactive Relational Database Connectivity: the non-blocking equivalent of JDBC for WebFlux.
CRUD
Create, Read, Update, Delete.
JWT
JSON Web Token: a signed token carrying claims (who you are, scopes, expiry).
OAuth2 / OIDC
OAuth 2.0 is the protocol for getting access tokens; OpenID Connect adds login (identity) on top of it.
RBAC
Role-Based Access Control.
CSRF / CORS
Cross-Site Request Forgery (an attack, protection is on by default in Spring Security) / Cross-Origin Resource Sharing (browser rule about which other sites may call your API).
MDC
Mapped Diagnostic Context: per-thread key/values (like traceId) that the logger adds to every log line.

Architecture, data & messaging

CAP
Consistency, Availability, Partition tolerance (see Q47).
ACID
Atomicity, Consistency, Isolation, Durability: guarantees of a database transaction (Q76).
BASE
Basically Available, Soft state, Eventually consistent: the looser model many NoSQL systems use.
SQL / NoSQL
Structured Query Language (relational databases) / "Not only SQL" (document, key-value, column, graph stores).
PL/SQL
Oracle's Procedural Language extension to SQL (Q78).
MVCC
Multi-Version Concurrency Control: databases keep old row versions so readers do not block writers.
TTL
Time To Live: how long a cache entry / message lives before it expires.
AMQP
Advanced Message Queuing Protocol: RabbitMQ's main protocol (version 0-9-1).
DLX / DLQ
Dead Letter eXchange / Dead Letter Queue: where failed or expired messages go.
ES
Elasticsearch, a search engine built on Apache Lucene.
ELK
Elasticsearch + Logstash + Kibana: the classic log stack (with Beats it is called the "Elastic Stack").
KQL
Kibana Query Language, e.g. level:ERROR and service:orders.
LB
Load Balancer: spreads requests over several instances.
K8s / HPA
Kubernetes (container orchestrator) / Horizontal Pod Autoscaler (adds pods when CPU or another metric is high).
SLA / SLO
Service Level Agreement (contract) / Objective (internal target), e.g. "99.9 % of requests under 300 ms".
p99
99th percentile latency: 99 % of requests are faster than this.
RPS / TPS
Requests / Transactions Per Second.
RFQ
Request For Quote: a client asks for a price (the "client → sales → trader" flow in Q65).

Build & delivery

POM
Project Object Model: Maven's pom.xml.
BOM
Bill Of Materials: a POM that only pins versions of many libraries (e.g. spring-boot-dependencies).
SNAPSHOT
A Maven version that is still changing (1.4.0-SNAPSHOT); a release version never changes.
CI / CD
Continuous Integration (build + test every change) / Continuous Delivery or Deployment (automatically ship it).
SCM / VCS
Source Code Management / Version Control System (Git, SVN).
SVN
Apache Subversion, a centralized version control system.
PR / MR
Pull Request (GitHub) / Merge Request (GitLab): a request to merge a branch, with review.
DAR
Deployment ARchive: the package format of DeployIT / XL Deploy / Digital.ai Deploy.
