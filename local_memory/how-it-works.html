How Local Memory works

Memory and learned habits for GitHub Copilot in VS Code. Plain files on your machine, one Python script with no dependencies, four hooks and a few skills. It costs no AI credits until you ask it to learn.

1. The big picture

Copilot never talks to a database. It reads a generated instructions file and the output of a session-start hook, and it writes memory by running mem.py through skills. Everything ends up as text files under ~/.copilot/local-memory/.

always loaded automatic (hooks) on request (skills) Copilot / the tool

2. The five kinds of memory

PieceWhat it holdsHow it reaches the agent
User memoryYour preferences, one fact per line (user.md)Instructions file, every session
Repository memoryCommands, conventions, gotchas of one repo (memory.md)Session-start hook, only inside that repo
InstinctsLearned habits: when X, do Y, with a confidence scoreSession start and instructions file once confidence ≥ 70%
Observation logYour prompts, failed tool calls, transcript paths (secrets redacted)Never loaded. Only /alx-reflect reads it
ConfigOptional config.json with the limitsRead by mem.py on every run

A repository is identified by its origin remote, so every clone and worktree shares one memory. No remote: identified by path.

3. What happens in a session

Hooks do the quiet work. They never block or fail a session: any error goes to hook-errors.log.

4. Skills: the parts that think

Hooks only log. Deciding what is worth keeping needs the model, so that part is a skill you trigger.

Nothing runs in the background. Reflect spends AI credits only when you type it.

5. An instinct’s confidence

New instincts start at 50%. Seeing the pattern again adds 10 points (cap 90%). A contradiction removes 20. Unused ones fade 10 points every 30 days. Below 20% they are deleted. Only instincts at or above 70% are loaded.

Instincts live per scope: repository for codebase conventions, global for habits that hold everywhere. A repository instinct seen in 2+ repositories is promoted to global. Each scope keeps at most 100 instincts.

8. Limits and privacy

Limits

  • A fact is one line, ≤ 300 characters
  • Per scope, loaded: newest facts up to 200 lines / ~4,000 chars
  • Instincts loaded: up to 10 per scope, ≥ 70%
  • Log rotates at 1 MB, 3 old copies
  • All numbers can be changed in config.json

Privacy

  • Everything stays on your machine, files are mode 0600
  • Secrets are redacted before anything is logged
  • Terminal commands: only the first word is logged
  • LOCAL_MEMORY_LOG=off stops all logging
  • User text always goes in through a quoted heredoc, never as shell arguments
